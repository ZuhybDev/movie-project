# Movie Project

This project is a movie discovery application built with React and Vite. It allows users to search for movies, view trending movies, and see detailed information about each movie.

## Features

- Search for movies using the TMDB API
- View trending movies
- Display detailed information about each movie
- Responsive design

## Technologies Used

- React 19
- Vite
- Appwrite
- Flowbite React
- Tailwind CSS
- ESLint

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:
   https://github.com/ZuhybDev/movie-project.git

## Environment Variables

- Create a `.env` file in the root of the project and add the following environment variables:
```bash
- VITE_TDMB_API_KEY=
- API_KEY=
- VITE_APPWRITE_ID=
- VITE_APPWRITE_DB_ID=
- VITE_APPWRITE_COLLECTION=
```
