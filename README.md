# Movie Project

This project is a movie discovery application built with React and Vite. It allows users to search for movies, view trending movies, and see detailed information about each movie.

## Features

- Search for movies using the TMDB API
- View trending movies
- Display detailed information about each movie
- Responsive design

## Technologies Used

- React 19
- Vite
- Appwrite
- Flowbite React
- Tailwind CSS
- ESLint

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)
